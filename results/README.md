# Results output guide

These files were generated by `N_gonorrhoeae_AMR_reproducible_analysis.ipynb` during the verified clean-kernel run.

## Tables

- `data_audit.csv`: sample alignment, missing labels, class counts, unitig counts, constant features, and duplicate-profile diagnostics.
- `model_eligibility.csv`: documents why azithromycin and ciprofloxacin were modelled and cefixime was not.
- `fold_class_counts.csv`: train/test sizes and test-fold class counts.
- `model_metrics_by_fold.csv`: fold-level classification metrics and confusion counts.
- `model_metrics_summary.csv`: metrics calculated from complete out-of-fold predictions plus fold means and standard deviations.
- `out_of_fold_predictions.csv`: one out-of-fold prediction per isolate and model.
- `best_model_by_antibiotic.csv`: best prespecified learned model by average precision.
- `bootstrap_confidence_intervals.csv`: profile-group bootstrap intervals for balanced accuracy, ROC AUC, and average precision.
- `subgroup_performance_by_continent.csv`: transparent eligibility counts and descriptive out-of-fold metrics by continent.
- `selected_feature_importance_by_fold.csv`: selected unitigs and their fitted importance in each fold.
- `unitig_importance_stability.csv`: importance aggregated across folds and weighted by selection frequency.
- `top_predictive_unitigs.csv`: top 20 predictive unitigs per antibiotic and model, with phenotype prevalence.
- `environment_versions.csv`: versions recorded by the notebook.

## Figures

- `class_balance.png`: susceptible and resistant counts.
- `model_comparison.png`: out-of-fold balanced accuracy, ROC AUC, and average precision.
- `best_model_diagnostics.png`: confusion matrix, ROC curve, and precision-recall curve for the strongest learned model per evaluated antibiotic.
- `robustness_summary.png`: profile-group uncertainty intervals and descriptive continent-level balanced accuracy.
- `top_unitigs_*.png`: fold-stability-weighted predictive importance plots.

## Completion record

`run_completion.json` is created only after the notebook verifies that all expected result files exist and the model summary contains no missing metrics.

The results remain exploratory because the supplied unitig matrices were already GWAS-filtered before this notebook's cross-validation. The unitig tables are predictive associations, not validated gene or mechanism assignments.
